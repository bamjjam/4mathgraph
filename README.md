# 4mathgraph

초등학교 4학년 수학 「5. 꺾은선그래프」 2·3차시에 쓰는 탐구 앱입니다.

같은 하루 기온 자료를 막대그래프, 꺾은선그래프, 겹쳐 보기로 바꾸어 보며 꺾은선그래프의 점과 선이 무엇을 나타내는지 살펴봅니다.

- 막대그래프 → 꺾은선그래프로 바꾸면 막대 끝에 점이 하나씩 찍히고, 막대가 사라진 뒤 점이 순서대로 선으로 이어집니다.
- '이름표 보기'를 켜면 제목, 단위, 가로 눈금, 세로 눈금, 점, 선에 이름표가 붙습니다.
- '물결선 보기'를 켜면 세로 눈금의 아랫부분(0~4°C)을 물결선으로 줄여 변화가 더 뚜렷하게 보입니다.
- 막대나 점을 누르면 그 시각의 기온이 나옵니다.

자료: 기상청 기상자료개방포털 방재기상관측(AWS) 시간 자료(소수 첫째 자리에서 반올림)
